LEBEDEVA STUDIO — исправленная полная версия.

ВАЖНО: Все файлы из этого архива должны находиться в КОРНЕ репозитория GitHub, а не внутри отдельной папки.

1. Откройте репозиторий marialebedeva156/lebedeva-studio.
2. Удалите старые файлы index.html, catalog.html и прочие файлы сайта (можно оставить .gitignore).
3. Нажмите Add file → Upload files.
4. Перетащите ВСЕ файлы из распакованной папки, включая .jpg, .png, .css, .html (не сам ZIP).
5. Нажмите Commit changes.
6. Подождите 1–3 минуты и обновите сайт Ctrl+F5.

ВНИМАНИЕ: my_passport_photo.jpg — личная фотография. На публичном сайте она доступна всем.
