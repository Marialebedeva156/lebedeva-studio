ИСПРАВЛЕННЫЙ САЙТ LEBEDEVA STUDIO

1. Распакуйте ZIP.
2. В папке лежат index.html, catalog.html, contact.html, dom.html, translit.html, algorithm.html и все изображения.
3. Откройте index.html в браузере и проверьте фотографии.
4. На GitHub в репозитории lebedeva-studio нажмите Add file -> Upload files.
5. Перетащите ВСЕ файлы из этой папки в КОРЕНЬ репозитория, не сам ZIP и не папку целиком.
6. Нажмите Commit changes, дождитесь публикации и обновите сайт Ctrl+F5.

Фотографии встроены прямо в HTML (data:image/jpeg;base64), поэтому они отображаются даже при проблемах с путями на GitHub.
Для открытия фото в новой вкладке файлы .jpg также включены отдельно.
ВАЖНО: фото учебного паспорта будет общедоступно на GitHub Pages.
