Условие задачи № 1017

Дано вещественное число A . Вычислить значение x :

  • если A < 10, то x = A⁴;
  • если A > 61, то x = A;
  • в остальных случаях (10 ≤ A ≤ 61) x = A − sin(A²).

В JavaScript функция Math.sin() принимает угол в радианах.

Введите A и нажмите «Вычислить x».

Описание алгоритма

  1. Получить вещественное число A из поля ввода.
  2. Если A < 10, вычислить A в четвёртой степени.
  3. Иначе, если A > 61, принять x = A.
  4. Иначе вычислить A − sin(A²).
  5. Показать x и использованную ветвь алгоритма.

Примеры проверки

  • A = 2 → x = 16.
  • A = 62 → x = 62.
  • A = 10 → x = 10 − sin(100).
  • A = 61 → x = 61 − sin(3721).
